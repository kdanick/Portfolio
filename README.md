# Portfolio V1

Welcome to **Portfolio V1** — the lightweight little corner of the internet
where I share my work and keep the updates rolling.

**Live site:** [kdanick.github.io/Portfolio](https://kdanick.github.io/Portfolio/)

## Why a Static Website?

I went with a static website because it is quick, simple, and happily hosted
through GitHub Pages. No backend, no database, no server bill — just a fun,
straightforward place to keep people updated while I work on the bigger plan.

Think of this as the temporary but intentional workshop display while the
main portfolio is still being designed behind the scenes.

And yes, I haven't quite found the right shades of color yet — I'm still
deciding exactly how it should look 😂. Apparently, being a perfectionist
about the details is a perfectly valid part of the creative process.

## Version 2

A new portfolio with custom domain hosting is currently in the making. It
